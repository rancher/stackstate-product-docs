== Overview

SUSE Observability provides xref:/use/alerting/k8s-monitors.adoc[monitors out of the box], which provide monitoring on common issues that can occur in a Kubernetes cluster. You can configure custom monitors from the {stackstate-product-name} dashboard for the metrics collected by {stackstate-product-name} or application metrics ingested xref:/use/metrics/k8s-prometheus-remote-write.adoc[from Prometheus].

== Steps to add a monitor:

Follow the below steps to add a new monitor to a component in {stackstate-product-name}:

. In the {stackstate-product-name} dashboard, naivgate to 'Monitors' and click 'ADD NEW MONITOR'.
+
image:monitors/add-new-monitor.png[]

. From the list of monitor types, choose the type that fits your use-case.
+
image::monitors/choose-monitor-type.png[]

. Fill in the various parameters for each monitor type, such as metrics, monitoring conditions, component mappings, and the like, as per your monitoring requirements.

. Click 'SAVE CHANGES' to add the monitor to the component.

== Verification

* Verify that the monitor has been added successfully by checking the list of monitors. From the list, you can further edit the monitor, change the state, or delete as needed.
