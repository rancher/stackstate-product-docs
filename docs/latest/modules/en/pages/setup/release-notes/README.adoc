== Agent chart 1.7.69 upgrade permissions

With OTel enabled, the agent chart now installs the CollectionDeclaration CRD by default and upgrades it with the chart.
Upgrades require cluster-scoped CRD permissions and fail if the installer lacks them.
Ask a cluster administrator to grant the installer CRD permissions, or set top-level `installCrds: false` before upgrading and have an administrator manage the CRD separately.
Declaration read/status permissions and existing YAML collection remain enabled.
Prometheus Operator CRDs retain their separate opt-in.
See xref:setup/otel/troubleshooting.adoc#collection-declaration-install-forbidden[CRD installation troubleshooting] for the Helm error and the override.
