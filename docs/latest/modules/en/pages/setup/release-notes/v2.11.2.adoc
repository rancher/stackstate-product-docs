== New Features & Enhancements

* *Backup Infrastructure Standardization:* Backup jobs now consistently apply scheduling, metadata, and security settings across all environments, introducing writable storage for configuration uploads alongside a new `backup.manualJobs.containerSecurityContext` override. 
** *Action Required:* Before upgrading, review any configuration security overrides under `backup.configuration.securityContext`, explicit empty values, enforced `backup`/`backup-v2` component labels, and the settings-PVC initializer’s fixed resource limits (`10m` CPU and `100Mi` memory).
* *Longhorn & Maintenance Support:* Improved Longhorn storage support by introducing per-component storage class overrides alongside updated deployment guidance. High Availability (HA) sizing profiles now feature an integrated replication checker to verify database health and replication status prior to initiating node maintenance. See xref:setup/install-stackstate/kubernetes_openshift/longhorn.adoc[Run SUSE Observability on Longhorn].

== Bug Fixes

* *StackPack CLI Upgrades:* Fixed a CLI error where the `unlocked` parameter was left undefined during StackPack upgrade operations.
* *Base Image Runtime Compatibility:* Resolved potential runtime compatibility issues by building ClickHouse directly from source on SUSE Linux Enterprise BCI, and replaced Elasticsearch's Ubuntu-sourced `tini` init binary with the BCI-provided `catatonit` init process.
* *Overview Timestamps:* Reinstated the *Last Updated* timestamp field (formerly *Updated On*) across default overview pages, updated to display a relative time difference rather than a static point in time.
